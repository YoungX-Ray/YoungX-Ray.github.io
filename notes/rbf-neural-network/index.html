RBF 径向基函数：看见神经元权重如何学习

发表于2026-09-22|更新于2026-09-22|神经网络
|浏览量:

如果你刚学完二阶系统，可以先做一个区分：控制模型用方程描述系统怎样运动；这里的 RBF 网络先解决一个更简单的问题——给定一批输入和目标值，怎样学习一条近似它们的曲线？ 本课不是闭环控制器，也不据此判断控制系统稳定性。

RBF 是 Radial Basis Function（径向基函数） 的缩写。先理解一个基函数，再理解多个基函数的加权组合，最后观察这些权重怎样被误差推动着更新。

建议顺序： 先读第 1–3 节，再到第 4 节播放动画；选中一个神经元，结合第 5 节理解它下一步为何增大或减小。也可以直接 宽屏打开训练动画 或返回 RBF 栏目。

1. 什么叫“径向”？只看离中心多远

取一个中心 \(c\)。如果函数只取决于输入 \(x\) 离中心的距离，而不取决于方向，它就是径向的。多维情形常写作 \(\varphi(\lVert\mathbf{x}-\mathbf{c}\rVert)\)；本课只用一维输入，此时距离就是 \(|x-c|\)。

我们选择最常见的高斯形式之一：

\[\phi_j(x)=\exp\left(-\frac{(x-c_j)^2}{2\sigma_j^2}\right),\qquad \sigma_j>0.\]

把它想象成以 \(c_j\) 为中心的“小山包”：

参数或位置 数学含义 图上怎么读
中心 \(c_j\) 第 \(j\) 个神经元最敏感的位置 山峰的横坐标
宽度 \(\sigma_j\) 距离衰减的尺度 大则宽，小则窄
\(x=c_j\) \(\phi_j=1\) 在中心激活最强
\(|x-c_j|=\sigma_j\) \(\phi_j=e^{-1/2}\approx0.607\) 离开一个宽度后变弱
\(|x-c_j|=2\sigma_j\) \(\phi_j=e^{-2}\approx0.135\) 更远时贡献通常很小

这里没有概率密度的归一化系数，所以峰值始终为 1。高斯只是 RBF 的一种选择，不能把所有径向基函数都等同于高斯函数。MathWorks 的 radbas 定义 使用 \(e^{-n^2}\)；令 \(n=(x-c)/(\sqrt{2}\sigma)\) 就与本课形式一致，宽度参数的不同写法需要换算。

2. 从一个“小山包”到一个 RBF 网络

设有 \(M\) 个高斯神经元，网络计算过程为：

输入 \(x\) → 到各中心的距离 → 各基函数激活 \(\phi_j(x)\) → 加权相加 → 输出 \(\hat y(x)\)。

\[\hat y(x)=b+\sum_{j=1}^{M}w_j\phi_j(x).\]

这里最容易混淆的是三个量：

量 表示什么 本课中什么时候变化
激活 \(\phi_j(x)\) 输入对这个神经元的激活程度，范围 \((0,1]\) 移动输入探针时变化
输出权重 \(w_j\) 这个神经元的信号以多大幅度、什么符号进入输出 训练迭代时变化
输出贡献 \(w_j\phi_j(x)\) 这个神经元对当前预测实际贡献多少 权重或输入变化都可能影响它

正权重把局部曲线向上抬，负权重向下拉；偏置 \(b\) 提供整体平移。多个局部贡献重叠，再加上偏置，就构成最后的拟合曲线。

权重不是概率，不必相加为 1，也不局限在 0 到 1。 单看权重大小也不能判断神经元在某个输入处有多重要，还要看它在该处是否被激活。

3. 这节课究竟训练哪些参数？

本课采用“固定基函数、学习线性输出”的入门版本：

  • 中心 \(c_j\)：均匀放在区间 \([-2,2]\) 上，训练时固定。
  • 宽度 \(\sigma_j=\sigma\)：所有神经元相同，由你在实验开始前选择。
  • 权重 \(w_j\) 与偏置 \(b\)：从 0 开始，通过梯度下降学习。

中心、宽度也可以用聚类或其他训练方法选择，甚至联合优化。本课暂时固定它们，是为了单独看清输出权重的作用。因此动画里中心不移动，不是程序没有训练，而是我们明确选择了只训练输出层。

固定基函数后，网络对输入 \(x\) 是非线性的，对待学习的 \(w_j,b\) 却是线性的，最小二乘误差是凸二次函数。这里全部权重从 0 初始化是可行的：不同中心产生不同特征列，并不存在所有隐藏神经元都从相同参数出发的对称性问题。

这个特例也可以直接求线性最小二乘解；我们使用迭代法，是为了观察学习过程。它不等于 MATLAB newrb 的流程：后者逐步增加径向基神经元，并重新设计线性输出层权重，见 官方算法说明。

4. 播放训练：把一次次更新连起来看

动画默认用 7 个神经元拟合：

\[y(x)=0.7\sin(1.8x)+0.22x,\qquad x\in[-2,2].\]

41 个等距、无噪声样本用于训练；图中的目标虚线还在样本之间绘制，方便你比较插值形状。所有曲线与权重都来自实际的数值迭代，可复现，没有预设一条“看起来越来越好”的动画轨迹。

宽屏打开训练动画 ↗

第一次看，按这个顺序操作：

  1. 保持默认参数，点“前进 1 次”。查看权重从 0 向哪些方向更新。
  2. 点“播放训练”，同时观察拟合曲线和权重条；随时暂停。
  3. 点击一个神经元，查看它的权重轨迹、基函数与加权贡献。
  4. 拖动迭代进度条回到第 20、100、1200 次，比较三个时刻。
  5. 保持迭代次数不动，只移动输入探针。激活值和预测会变，权重不会变。

播放速度只改变每秒展示多少次迭代，不改变学习率。改变神经元数、宽度、学习率或目标函数，会从相同的零初始化重新训练。CSV 下载包含当前参数下完整的第 0–1200 次记录，包括全部权重、偏置和训练 MSE。

为什么默认例子中有一个权重几乎不动？ 默认目标是奇函数，样本和中心又关于 0 对称，位于中心 0 的神经元和输出偏置会收到相互抵消的梯度，因此它们保持接近 0。这是这个对称例子的结果，不是每个权重都必须在每一步变化。把目标切换为“两个局部起伏”，可以观察不对称情况下的更新。

5. 一个权重为什么会增大或减小？

对第 \(i\) 个训练样本，定义预测误差：

\[e_i=\hat y_i-y_i.\]

我们最小化的损失是半均方误差：

\[L=\frac{1}{2N}\sum_{i=1}^{N}e_i^2.\]

界面显示的是通常的 \(\mathrm{MSE}=\frac{1}{N}\sum_i e_i^2=2L\)。这个 \(1/2\) 使求导后公式更简洁，不改变最小值所在的位置。

由于 \(\partial\hat y_i/\partial w_j=\phi_j(x_i)\)，有：

\[\frac{\partial L}{\partial w_j}=\frac{1}{N}\sum_{i=1}^{N}e_i\phi_j(x_i),\qquad \frac{\partial L}{\partial b}=\frac{1}{N}\sum_{i=1}^{N}e_i.\]

设学习率为 \(\eta>0\)，一次更新为：

\[w_j^{(k+1)}=w_j^{(k)}-\eta\frac{\partial L}{\partial w_j},\qquad b^{(k+1)}=b^{(k)}-\eta\frac{\partial L}{\partial b}.\]

公式对应的直觉是：某个神经元激活强的位置，如果预测普遍偏低，误差 \(e_i\) 往往为负，它的权重就倾向增大；如果预测普遍偏高，就倾向减小。不同样本的影响可能抵消，最终取决于加权误差的总和。

用一个样本手算一次。 假设只有一个训练样本，目标为 1，当前预测为 0，某神经元的激活为 0.607，学习率为 0.1，当前权重为 0。则误差为 \(-1\)，权重梯度约为 \(-0.607\)，下一步权重约为 \(0-0.1\times(-0.607)=0.0607\)。偏置也会更新为 0.1。注意：网页实验使用全部 41 个样本计算梯度，这个单样本例子只用于看清符号。

实验下方显示选中权重的实际下一步计算。小数显示会舍入，计算内部使用未舍入的浮点数。

6. 用三组对比理解拟合能力

6.1 只有 3 个神经元：能学习，但能表达的形状有限

先完成默认训练，再选“只有 3 个”。训练误差仍可能下降，但少量基函数可能不足以表达目标的局部变化。继续训练能够改善优化程度，却不能随意突破这组固定基函数的表达能力。

6.2 基函数过窄：中心之间容易留下空隙

保持 7 个神经元，把宽度调成 0.18。每个神经元只在很小的邻域明显激活，中心之间可能出现难以覆盖的区间。增大一个权重主要抬高一个局部峰，未必能补好峰之间的曲线。

反过来，宽度很大时，各神经元的激活形状更相似，可能需要多个正负权重相互配合，优化也可能变慢。宽度并非越大或越小越好，应结合数据尺度、中心间距与验证误差选择。

6.3 学习率更大：在本实验范围内通常走得快，但不是越大越好

比较 0.02、0.08 和 0.20。看达到相近误差需要多少次迭代，而不只是比较播放了多少秒。此处只提供经过校验的温和学习率；一般情况下，过大的学习率会造成振荡或发散。

误差曲线使用对数纵轴，不能把相同的视觉下降高度解释为相同的误差差值。本实验没有噪声、没有独立验证集，所以低训练误差不能证明实际任务的泛化效果；训练区间之外，高斯激活逐渐趋近 0，输出趋近偏置，外推也需要谨慎解释。

7. 四个自测问题

先回答，再打开答案。

1. 移动输入 x 后，神经元颜色变了，是否说明它又训练了一次？

不是。节点深浅表示当前输入下的激活值。移动输入改变的是激活与预测；训练才改变输出权重和偏置。

2. 某个神经元的权重很大，它一定主导所有输入位置的预测吗？

不一定。在远离它中心的位置，激活可能接近 0，实际贡献是权重与激活的乘积，仍可能很小。

3. 宽度固定时，负权重会把高斯函数的中心移走吗？

不会。中心与宽度决定位置和形状；负权重使加权贡献向下，绝对值决定幅度。它不会移动中心。

4. 误差还在下降，但曲线仍不够贴合，继续迭代一定能完全拟合吗？

不一定。可能还未优化充分，也可能受限于当前神经元数、中心和宽度。需要区分“参数还没学好”与“这组基函数表达不了”；实际应用还需检查验证集表现。

掌握这一步后，你就能把 RBF 看成一组局部特征的可学习组合。后续可以继续研究中心选择、宽度优化、多维输入，以及用 RBF 逼近控制系统中的未知非线性；这些内容需要各自的建模与稳定性分析。

参考定义与算法：MathWorks radbas、MathWorks newrbe 的线性输出层求解、MathWorks newrb 的逐步增添神经元方法。本页使用自行实现的固定基函数梯度下降演示。
