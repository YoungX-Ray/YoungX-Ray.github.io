01 / 先看 P 和 PD

极点左移，衰减通常更快

点击 P，然后增加 Kp：这时极点实部一直是 −0.6，振荡频率升高，却不能只凭 Kp 增大就断言更快收敛。再增加 Kd，观察极点实部和超调怎样变化。

Ki = 0 时，闭环分母为 s² + (1.2 + 4Kd)s + 4 + 4Kp。P 和 PD 的稳态输出是 Kp/(1 + Kp)，一般存在阶跃跟踪误差。

02 / 再加入积分

消除误差，同时多配置一个极点

点击 PI，观察输出趋于 1。积分能在闭环稳定时消除阶跃稳态误差，但 Ki 太大会让极点越过虚轴。点击“失稳例子”验证这一点。

Ki ≠ 0 时，特征多项式为 s³ + (1.2 + 4Kd)s² + (4 + 4Kp)s + 4Ki。三阶 Hurwitz 条件：各项系数为正，且 (1.2 + 4Kd)(4 + 4Kp) > 4Ki。

03 / 用目标反算 PID

三个系数，对应三个增益

将目标二阶因子乘上 (s + p)，逐项比较系数，即得：

Kd = (2ζωₙ + p − 1.2) / 4Kp = (ωₙ² + 2ζωₙp − 4) / 4Ki = pωₙ² / 4

试一试 ζ = 0.7、ωₙ = 3、p = 8。点击“计算 PID 并应用”，验证特征根到达 −2.1 ± j2.142 与 −8。

为什么配置了 ζ = 0.7，超调不一定等于标准二阶公式？

真实闭环还包含第三个极点和 PID 引入的零点。标准二阶超调公式只直接适用于无零点的标准二阶传递函数；本页用完整闭环计算阶跃响应，没有用该公式代替仿真。图中的目标 ζ、ωₙ 只描述目标二阶因子。把第三极点放得很远也不等于零点影响消失。

极点图绘制闭环特征多项式的根。若发生精确零极点相消，输入到输出的最小传递函数阶次可能更低，但内部特征模态仍可能存在。例如 Kp = 1.2、Ki = 4、Kd = 1 时，T(s) 可约为 4/(s+4)。

根轨迹与“拖动 PID 滑块”的区别是什么？

根轨迹针对一个固定的开环形状 L(s) = C(s)G(s)，只改变整体比例 κ，求 1 + κL(s) = 0 的根。改变 Kp、Ki、Kd 中某一个会改变零点及开环形状，因此会重新生成一组根轨迹。图中实心点总是 κ = 1，也就是当前控制器。κ → 0 的端点为开环极点；Ki = 0 时使用二阶表达式，不人为添加原点极点。

这个实验采用什么 PID 模型？

本页采用连续时间、理想并联 PID，微分作用于误差；不包含执行器饱和、采样或微分滤波。单位阶跃会使理想微分项产生控制冲击，响应计算已计入其作用，输出 y 本身连续。实际带滤波的微分会增加动态阶次，不能直接沿用这里的三阶系数匹配。

超调与调节时间按当前时间窗采样计算，调节带相对于输出自身终值；“窗口内未确认”表示需延长观察，不代表系统一定不稳定。原对象曲线表示把同样单位阶跃直接输入 G(s)，用途是比较动态形状，不表示闭环跟踪基准。
