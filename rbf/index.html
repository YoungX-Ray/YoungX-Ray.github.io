RBF 径向基函数

RBF 径向基函数

新主题 · 神经网络与函数逼近

一组局部的“小山包”，怎样拼出一条复杂的曲线？从径向基函数开始，看见每个神经元如何通过权重更新参与拟合。

第一课 · 从直觉到迭代

RBF：看见权重如何学习

先读懂中心、宽度与激活，再理解神经元的加权求和。用一维函数拟合，把梯度下降的每一步落实到可读的数字与曲线上。

  1. 认识一个神经元：高斯基函数、距离、中心与宽度。
  2. 组合成网络：区分激活、权重和实际输出贡献。
  3. 看见学习过程：播放训练、选择神经元、回看任意迭代。
  4. 自己做对比：改变神经元数、宽度和学习率，解释拟合差异。

这节课的边界

固定各神经元的中心与宽度，只训练输出权重和偏置；数据无噪声，用来理解学习机制。

先修要求：函数图像、指数函数与求和。梯度公式逐步解释；你也可以先观察动画，再回头读推导。
